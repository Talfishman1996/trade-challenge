# P10.3 Summit Ledger Design System

Captured: 2026-07-12 PDT

State: `EVIDENCE_READY`

Evidence ID: `EV-P10-DS-003`.

## Direction

`Summit Ledger` combines a restrained alpine monument with an editorial field
ledger. Operational truth is mineral, precise, and quiet. Ceremony is earned only
when a meaningful milestone occurs. Complexity lives in evidence and recovery, not
in simultaneous decoration.

## Type

| Role | Family | Weight/shape | Use |
|---|---|---|---|
| display | Barlow Semi Condensed | 600-700 | route titles, equity, milestone ceremony |
| language | Barlow | 400-600 | labels, body, controls |
| numeric/data | JetBrains Mono | 500-700, tabular | money, percentages, timestamps, IDs |

Minimum body is 15/21 px. Supporting text is 13/18 px and never contains the only
assumption or action. Dynamic type uses `clamp()` without clipping; values may wrap
at semantic separators rather than shrink below 14 px.

## Geometry

- Spacing scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64 px.
- Page gutter: 16 px at 320-374, 20 px at 375-430, 24 px above.
- Touch target: 48 px default; 56 px primary/nav actions.
- Radius: 8 control, 14 card, 20 sheet, full pill only for status/filter chips.
- Border: 1 px default; 2 px selected; no low-contrast glass-only boundary.
- Elevation: tonal surface plus one controlled shadow. Blur cannot carry hierarchy.
- Content width: 480 px mobile canvas maximum.

## Layout Primitives

`AppFrame`, `SafeArea`, `PageHeader`, `Section`, `Stack`, `Inline`, `Grid`,
`StickyActionBar`, `ScrollRegion`, and `EvidencePlate`. Primitives own spacing;
screens cannot invent arbitrary margins.

## Controls

Required audited primitives: `Button`, `IconButton`, `NavigationItem`,
`SegmentedControl`, `Field`, `MoneyField`, `OutcomePicker`, `SliderField`,
`SwitchField`, `Chip`, `SearchField`, `SelectSheet`, `RecordCard`, `StatusReceipt`,
`Warning`, `BottomSheet`, `Dialog`, `Toast`, `ChartFrame`, `Skeleton`, `EmptyState`,
and `ErrorBoundary`.

Every control specifies default, hover where available, pressed, focus-visible,
selected, disabled, loading, invalid, and read-only states. Icon-only controls have
an accessible name and visible tooltip/help on long press or focus where ambiguity
remains.

## Core Patterns

### Operational Monument

- Compressed height: 172-210 px depending on viewport.
- Mountain is a lightweight CSS/SVG silhouette, not an 8 MB raster.
- Equity and current segment remain foreground-readable without glass blur.
- Ambient motion is absent. A single path reveal is allowed on first milestone
  transition and disabled under reduced motion.

### Next Risk Plate

Dollar risk is the largest value; percentage, strategy equity, gross 1:1, and model
ID are visible. Activating details reveals anchor segment and validity boundaries.

### Consequence Receipt

Shows record outcome, entered realized net P&L, previous/new strategy equity, prior/
next planned risk, local revision, sync state, and Edit. It is compact on Today and
complete on record detail.

### Record Card

One clear open target. Outcome glyph, instrument, date, signed net P&L, equity after,
R snapshot, and durability state. Actions are in a separately named menu.

### Evidence Plate

Starts with a question, then value/chart, interpretation, provenance, and action.
Charts never float as unexplained decoration.

## Data Visualization

- Use inline SVG with semantic labels and a visible textual summary.
- Equity path: realized line only; simulation bands are never overlaid without a
  legend and different texture.
- Risk curve: dollar and percentage require separate scales/plates.
- Max two emphasized series. Grid and axes meet 3:1 non-text contrast.
- Tooltips are keyboard/touch reachable and values also exist in an adjacent table
  or summary.
- Empty/insufficient data is a labeled state, not a zero chart.

## Motion

- Press/focus: 80-120 ms.
- Route/sheet: 160-220 ms, ease-out, no content-loading stagger.
- Receipt: 180 ms in, 2.4 seconds stable, 180 ms out.
- Delete undo timer is conveyed by text/time, not animation alone.
- No looping shimmer, pulse, ray, particle, parallax, or glow.
- Reduced motion removes transforms, path drawing, smooth scrolling, and ceremonial
  transitions while preserving instantaneous state changes.

## Feedback and Layering

`content < sticky actions < navigation < sheet backdrop < sheet < dialog < toast`.
Sync receipts sit above navigation and below sheets. Persistent failures become a
shell state and System item, never a permanent floating block over tabs.

## Accessibility Contract

- WCAG 2.2 AA contrast targets; 4.5:1 text, 3:1 large text/graphics/focus.
- Logical heading order and landmarks on every route.
- Form labels use explicit associations; errors use `aria-describedby` and a live
  summary on submit.
- Dialog focus trap/return, Escape/Back behavior, and background inertness.
- Status messages use polite live regions; destructive/recovery failure is assertive.
- At 200% text, no primary action, amount, status, or assumption is clipped.
- Touch target and spacing checks run against every primitive state.
