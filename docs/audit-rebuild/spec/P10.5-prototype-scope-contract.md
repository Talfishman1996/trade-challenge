# P10.5 Prototype Scope and Acceptance Contract

Captured: 2026-07-12 PDT

State: `EVIDENCE_READY`

Evidence ID: `EV-P10-SCOPE-005`.

## Purpose

Reviewers evaluate product direction, interaction truth, information hierarchy,
visual identity, mobile behavior, and recovery design. They do not evaluate live
cross-device infrastructure, exchange execution, or production security.

## Acceptance Matrix

- W01-W17 each have an executed evidence record or an explicit simulated-boundary
  assertion.
- 320x568, 360x800, 390x844, 430x932, and 844x390 render without page-horizontal
  overflow or obscured primary actions.
- Capture remains usable with a mobile keyboard proxy and long validation messages.
- All model anchors and P7 vectors match; no legacy `$20K` or power-decay claim
  appears in prototype UI/code.
- Every local mutation has a visible record-specific receipt and stable UID.
- Search finds instrument, note, strategy, tag, and display ID in large-data fixture.
- Delete/Undo affects only the selected record.
- Offline/failure/conflict cannot display Verified or Synced.
- All controls are named, focusable, keyboard-operable, and >=44x44.
- Reduced motion removes all nonessential animation.
- Performance budgets in P10.4 are measured and reported, not assumed.
- No request targets production or any external data endpoint.
- Original tag/tree and production URL are unchanged.

## Reviewer Script

1. Start `empty`; inspect risk and log a Loss with manual negative P&L.
2. Observe device receipt and changed next risk; edit the record note.
3. Delete and undo the same record.
4. Switch to `normal`; search BTC and inspect Performance/Plan provenance.
5. Switch to `drawdown`; inspect explanation and complete a review.
6. Switch to `offline`; log a trade, then simulate reconnect and verification.
7. Switch to `sync-error` and `conflict`; recover without false success.
8. Switch to `large-data`; search/filter and inspect bounded rendering.
9. Switch to `target-reached`; confirm no post-challenge recommendation.
10. Test large text, reduced motion, short landscape, Back, and reload.

## Non-Goals

- no production replacement or current-data migration;
- no live exchange connection, order sizing, liquidation calculation, or API keys;
- no live cross-device sync, authentication, secrets, or security certification;
- no new probabilistic research beyond frozen published scenarios;
- no human pilot, telemetry, localization, PWA/native integration, or 10,000-user
  capacity exercise;
- no Telegram, screenshot binary lifecycle, or real import/export;
- no claim that prototype code is production-hardened.

## Gate Rule

Implementation cannot silently reduce this contract. A capability may be removed
only by a recorded scope decision; a simulated capability must remain visibly
simulated in the interface and evidence dossier.
