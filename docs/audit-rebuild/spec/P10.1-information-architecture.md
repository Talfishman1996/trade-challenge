# P10.1 Information Architecture Specification

Captured: 2026-07-12 PDT

State: `EVIDENCE_READY`

Evidence ID: `EV-P10-IA-001`.

## Product Frame

The prototype is a mobile expedition ledger for one repeated loop:

`size -> execute elsewhere -> record -> verify durability -> understand consequence -> review`

The app is not organized around available charts. It is organized around the user's
question at that moment. Each durable object and control has one primary home.

## Stable Route Map

| Route | Label | Owns | Does not own |
|---|---|---|---|
| `/prototype/today` | Today | current strategy equity, exact next risk, last accepted record, durability summary, immediate consequence, current challenge segment | full history, projection controls, data administration |
| `/prototype/journal` | Journal | search, filters, trade records, record detail, edit, recoverable delete, review status | aggregate dashboard widgets, global settings |
| `/prototype/insights` | Insights | performance, behavior evidence, drawdown, progress, projections, model provenance | record mutation, sync administration |
| `/prototype/insights/performance` | Performance | realized performance and canonical equity path | projections |
| `/prototype/insights/review` | Review | recurring review packet and data sufficiency | raw settings |
| `/prototype/insights/plan` | Plan | model curve, milestone progress, simulation assumptions | execution promises |
| `/prototype/system` | System | sync detail, storage, model identity, risk controls, display, export/import capability disclosure | daily operating metrics |
| `/prototype/system/sync` | Sync detail | checked/uploaded/merged times, record states, retry, diagnostics | global success celebration |
| `/prototype/review` | Review harness | deterministic scenario and viewport controls | production capability claims |

Unknown routes resolve to Today with a replace-state notice. Browser Back traverses
destinations and nested Insights/System routes. Reload restores the route and safe
query state, not an unsaved submission or open destructive confirmation.

## Global Shell

- Top app bar: current destination, prototype disclosure, one compact durability
  affordance. It never overlays tabs or content.
- Bottom navigation: Today, Journal, Capture, Insights, System. Capture is a named
  56 px action, not an unnamed decorative notch.
- Durability affordance states: `on-device`, `waiting`, `syncing`, `verified`,
  `offline`, `attention`. Activating it opens `/prototype/system/sync`.
- Ordinary successful background sync produces a 2-3 second nonblocking receipt
  above bottom navigation, then disappears. Failure remains discoverable in the
  shell until resolved.
- Every route reserves top/bottom safe areas and a keyboard-safe action region.

## Overlay Contract

| Surface | Form | Back/dismiss behavior | Restoration |
|---|---|---|---|
| Capture | full-height bottom sheet on portrait; full page on short landscape | Back closes only after discard check when meaningful input exists | invoking route and scroll restored |
| Record detail | route-backed sheet from Journal | Back returns to exact search/filter/scroll anchor | record ID in route/query |
| Record actions | action sheet | outside tap/Back closes; destructive action requires next state | none |
| Delete confirmation | alert dialog | focus trapped; explicit Cancel/Delete | none |
| Next-risk explanation | route-backed sheet | Back returns to Today | equity/model version encoded in displayed snapshot |
| Projection assumptions | route-backed disclosure | Back returns to Plan state | scenario query preserved |
| Toast/receipt | nonmodal live region | auto-dismiss except actionable failure | durable detail remains in destination |

Only one modal layer may be open. Toasts never cover primary controls or navigation.
Sheets use a visible title, Close control, initial focus, dialog semantics, and focus
return.

## Destination Hierarchy

### Today

1. Compact operational monument: strategy equity, target segment, durability dot.
2. Next planned risk: dollar amount first, percentage second, model ID available.
3. Primary `Log trade` action.
4. Last consequence receipt: outcome, net change, new equity, next risk, sync state,
   direct Edit.
5. Current condition: drawdown/streak/review due only when actionable.
6. Challenge trail: compact milestone strip; expansion is optional and ceremonial.

### Journal

1. Search field.
2. Filter/sort trigger with active-filter count.
3. Results count and review range.
4. Virtualized chronological record list.
5. Empty/no-result/error states with a next action.

### Insights

1. Stable sub-navigation: Performance, Review, Plan.
2. One question per evidence plate.
3. Data sufficiency/provenance adjacent to conclusions.
4. Assumptions adjacent to simulations.

### System

1. Sync and storage health.
2. Model and calculation identity.
3. Retained risk controls with explicit semantics.
4. Display/accessibility preferences.
5. Data export/import and prototype capability disclosure.
6. Destructive reset isolated at the end.

## State Restoration Keys

| State | Persistence | Rule |
|---|---|---|
| destination/sub-route | URL/history | always safe to restore |
| Journal query/filter/sort | URL query | normalize invalid values |
| Journal scroll anchor | session memory | restore by record ID, not pixels |
| Plan scenario | URL query | only whitelisted WR/horizon values |
| open Capture data | device draft transaction only | hidden implementation recovery, no Saved Drafts library |
| open destructive dialog | none | never restore |
| sync/outbox | fixture adapter storage | independent of route lifecycle |
| review harness scenario | URL query | explicit prototype-only state |

## Responsive Contract

- Primary design width: 320-430 CSS px portrait.
- 431-767 px: same one-column hierarchy with larger gutters; no desktop dashboard
  mutation.
- Short landscape: full-page Capture; persistent bottom actions move into document
  flow when keyboard geometry cannot be guaranteed.
- 768 px and above: centered 480 px mobile canvas plus optional review rail; the
  product remains mobile, not a stretched desktop grid.
- No horizontal page scrolling. Charts may pan only when visibly disclosed and
  must provide a textual summary.

## Ownership Proof

- Today answers "what now and what changed?"
- Journal answers "what exactly happened?"
- Insights answers "what does the evidence suggest?"
- System answers "is the system/model/data healthy and configurable?"
- Capture answers "what record am I committing?"

No other surface may duplicate a primary answer without a concise link to its owner.
