## Interpolation

For each anchor, define `x_i = ln(E_i)` and `y_i = E_i * r_i`. Compute
shape-preserving piecewise-cubic Hermite slopes from adjacent secants using the
weighted harmonic-mean PCHIP rule and one-sided shape-preserving endpoint slopes.
For `E` within an anchor interval, evaluate the cubic Hermite polynomial at
`x = ln(E)`, clamp numerical overshoot to `[y_i, y_(i+1)]`, then:

```text
dollarRisk(E) = PCHIP(ln(E); x_i, y_i)
riskFraction(E) = dollarRisk(E) / E
```

Float64/full precision is canonical. Display rounding never feeds back into the next
calculation. Execution quantity rounding belongs to a separate venue calculator.

## Boundary Policy

```text
E <= 0                 -> invalid/terminal; no recommendation
0 < E < 100,000        -> riskFraction = 0.15; dollarRisk = 0.15 * E
100,000 <= E < 10,000,000 -> PCHIP rule
E >= 10,000,000        -> target reached; no challenge recommendation
```

A post-target analysis extension may hold dollar risk at `$300,000`, making risk
fraction `300,000/E`, but must be labeled noncanonical and cannot drive Next Risk.
