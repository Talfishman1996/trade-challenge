## Detailed Findings

### Capture integrity

The detailed record surface can retain its full field set, but the minimum path is
unsafe because outcome is preselected. `Save & Add Another` also carries seven
pieces of state forward. That can be useful for repeated executions, but it needs an
explicit retained-state summary so an inherited loss, direction, strategy, or size
cannot become an unnoticed next-trade assumption.

### Delete semantics

Deleting trade #8 removed it immediately and closed the editor. The Trades screen
then offered Undo, but the store's undo operation is a separate last-addition stack:
it does not restore explicit deletions. Activating it would remove a different trade.
This opens `F-UX-HIGH-002`.

### Retrieval at account lifetime scale

Ticker and outcome filters correctly produced an empty intersection, but retrieval
has no text/date lookup. Combined with the existing 500-row, 39,961 px history
surface, this means old-record discovery becomes scrolling plus categorical guessing.
This opens `F-UX-HIGH-003`.

### Offline recovery truth

Offline capture is locally responsive and labels the write honestly. The reconnect
contract is incomplete: `handleConnectivity` sets Ready and records “Device is back
online” but never calls `runSync`. Upload waits for a later interval or focus event.
This opens `F-SYNC-HIGH-008`; it is separate from `F-SYNC-CRITICAL-006`, which covers
an attempted sync failure being mislabeled Synced.

### Manual sync semantics

The floating status control is actionable and non-blocking. During a deterministic
slow request it becomes disabled and labeled Syncing, then emits a brief completion
message. A no-change run keeps the age of the last data write, however, so Settings
must distinguish “last checked,” “last uploaded,” and “last downloaded/merged” if
those times answer different trust questions.

### Capability gaps

- Desktop browser automation cannot certify physical iOS suspension, virtual
  keyboard geometry, OS sharing, or a real cross-device handoff.
- The browser control surface rejected local file injection and did not surface the
  programmatic anchor download; source confirms these paths, not the mobile browser
  integration behavior.
- The isolated fixture intentionally resets its state on reload, so browser evidence
  cannot certify Settings reload persistence. Source only establishes a best-effort
  localStorage write whose errors are swallowed.

## Required Workflow Contract

The rebuild must treat each workflow as a state machine with explicit local commit,
cloud queue, cloud acknowledgement, conflict, failure, and recovery states. Every
destructive action needs an object-specific reversible period or a clearly labeled
irreversible confirmation. Search must target durable record fields, and projections
must display the assumptions needed to interpret their result.
