# P11.3 Core Vertical Slice

Evidence ID: `EV-P11-FLOW-003`

The implemented primary loop is:

`Today -> next planned risk -> Log trade -> explicit outcome/instrument/direction/net P&L -> local receipt -> recalculated equity/risk/progress`.

Capture never preselects an outcome or invents P&L. Realized net P&L is entered
manually and the copy requires actual fees, slippage, and funding to be included.
Create and update commit to the isolated ledger before simulated continuity begins.
Execution snapshots preserve model ID, model equity, planned risk percentage, and
planned dollar risk at acceptance time.

Nine deterministic Node tests pass, including exact P7 anchors/vectors, decreasing
risk percentage with increasing dollar risk, no post-target recommendation, explicit
capture validation, cent-exact money, invalid timestamp containment, equity
derivation, tombstones, and searchable fields. Capture also supports a guarded
Save-and-log-another loop and 650ms quiet edit autosave without duplicate revisions.
