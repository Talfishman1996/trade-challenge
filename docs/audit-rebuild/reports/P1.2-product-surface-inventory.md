Captured: 2026-07-12 PDT

## Navigation Model

The application has no URL router. `App.jsx` holds one `tab` state with four values:
`home`, `trades`, `analysis`, and `settings`. Mobile adds an unlabeled center action
between the second and third navigation items; desktop moves the same four views and
trade action into a fixed left rail.

Persistent shell surfaces:

- main scrolling content container
- four-view mobile bottom navigation or desktop side rail
- center/new-trade action
- floating mobile sync button or compact desktop sync control
- trade-entry bottom sheet
- risk-gate overlay
- milestone celebration overlay
- transient success/error toast
- lazy-load and error-boundary fallbacks

The source comment `Sync Gate — shown on fresh device with no data` has no rendered
gate implementation beneath it. Fresh-device entry currently proceeds directly to
the regular shell while boot sync runs.

## Browser-Observed Empty Baseline

Seven raw DOM snapshots are preserved as `EV-P1-SRC-003` under
`output/audit-rebuild/P1/surfaces/`:

1. Home showed `$20K`, zero trades, no win-rate/streak data, 100% next-trade risk,
   and six uncleared summit milestones.
2. Trade History showed its first-trade empty state and two log-trade entry points.
3. Performance showed no-data guidance.
4. Behavior showed enrichment-specific no-data guidance.
5. Projections rendered a full 500-path model despite no logged trades.
6. Settings exposed every control and described sync as an always-on shared vault.
7. Trade Entry exposed a bottom sheet with manual P&L and disabled save actions.
