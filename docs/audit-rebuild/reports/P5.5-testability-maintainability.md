# P5.5 Testability and Maintainability

Captured: 2026-07-12 PDT

State: `EVIDENCE_READY`

Evidence ID: `EV-P5-OPS-005`.

## Current Gate

`package.json` offers build/preview/deploy only. There is no lint, typecheck, unit,
component, integration, end-to-end, model-parity, migration, accessibility, visual,
or bundle-budget command. GitHub Actions builds and deploys GitHub Pages from
`master`; Cloudflare Pages/Worker deploys remain separate manual scripts. The live
product authority and CI authority can therefore diverge.

This opens `F-OPS-HIGH-003` for split deployment authority and strengthens
`F-OPS-HIGH-002` for absence of quality gates.

## Required Verification Stack

- TypeScript strict mode for contracts and migrations.
- ESLint plus import/boundary rules.
- Vitest for pure domain/storage/sync units.
- property/invariant tests for model, merge, ordering, idempotency, and migrations.
- React Testing Library for component state contracts.
- Playwright for W01-W17, routing, offline, failure, keyboard, and viewport flows.
- axe plus manual screen-reader/keyboard checks.
- deterministic screenshot comparison for states/viewports/directions.
- build budgets and zero-console-warning assertion.

CI order: install lockfile -> lint -> typecheck -> unit/property -> component ->
build/budgets -> isolated end-to-end/accessibility -> deploy immutable preview. A
single declared production pipeline promotes a validated artifact; hosting and Worker
releases expose version/commit and rollback independently.
