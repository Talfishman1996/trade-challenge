The page opts into `viewport-fit=cover` but only consumes the bottom safe-area inset.
There is no top/left/right inset handling, `visualViewport`/keyboard adaptation, or
height-aware breakpoint. Fixed navigation, floating sync, toast, risk overlay, and
90vh sheet can overlap each other or system UI. Browser-tab mode itself works; no
PWA/native scope is required.

`F-UI-CRITICAL-001` remains a release blocker. Physical WebKit/Android and keyboard
proof is required in P12 before any production recommendation.
