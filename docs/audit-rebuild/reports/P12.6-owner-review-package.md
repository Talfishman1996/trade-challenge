# P12.6 Owner Prototype Review Package

Evidence package state: `AWAITING_OWNER_REVIEW`

Staging: <https://summit-ledger-prototype.pages.dev/>

Review harness: <https://summit-ledger-prototype.pages.dev/prototype/review>

Recommended review sequence:

1. First launch: log a manual Loss, inspect receipt/equity/risk.
2. Save-and-log-another; verify every correctness-critical field resets.
3. Edit the record and pause; verify quiet autosave revision.
4. Delete, Undo, then repeat and wait eight seconds; recover in System.
5. Normal: use all Journal filters and inspect Performance/Plan.
6. Drawdown: inspect provenance, save a required decision note, confirm review closes.
7. Offline/error/conflict: confirm no false Verified state.
8. 500 records: search a late record and confirm bounded list.
9. Target/terminal: confirm both withhold a next recommendation for different reasons.
10. Large text/reduced motion and device Back/reload.

Known limitations: synthetic ledger, simulated sync/conflict/import/export/media,
fixed approved 65-month horizon, no Telegram, no physical-device certification, and
no production data. Owner feedback must be recorded and dispositioned before G12 can
pass; Codex cannot self-approve on the owner's behalf.
