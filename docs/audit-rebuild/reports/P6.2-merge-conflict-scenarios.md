## Target Rules

- Server revision orders accepted mutations; device wall clocks are metadata only.
- Create/edit/delete/restore are explicit commands against UID and base revision.
- Concurrent edits return field/object conflicts instead of silent whole-record LWW.
- Initial equity/model/settings changes are versioned account commands.
- Tombstones are retained until every registered device/backup horizon has advanced
  beyond their revision, then compacted by policy.
