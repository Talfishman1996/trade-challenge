## Judgment

The monument has a visual voice; the application does not. The body UI reads like a
generic developer dashboard, while near-every number is monospaced and bold. This
flattens numeric hierarchy: portfolio, risk, win rate, filters, tags, timestamps, and
chart axes all speak with similar mechanical emphasis.

## Target Type Roles

| Role | Direction | Rule |
|---|---|---|
| Monument/display | Cinzel | Restrict to `$10M`, milestone ceremony, and rare section marks. |
| UI/editorial | self-hosted Barlow | Use for headings, labels, instructions, and journal prose. |
| Numeric/data | JetBrains Mono | Use only for values that benefit from tabular alignment. |
| Charts | same numeric family | Remove unavailable Source Code Pro references. |

Minimum body/help text is 13 px at normal scaling; assumptions and warnings are at
least 14 px. Numeric formatting must preserve sign, currency, precision, and scale
without relying on color. Large portfolio values need tested compact and full-value
variants. The 200% emulation result was visually unchanged and is not proof of iOS
text scaling; physical validation remains open.
