The main problem is not line count alone. Domain decisions can only be exercised
through React hooks/components, synchronization is split across App/store/Settings,
and Home contains an asset/rendering subsystem inside the operational view.

## Target Boundaries

```text
app/          routes, shell, providers, error/recovery boundaries
domain/       pure versioned trade, outcome, risk, projection, merge contracts
features/     capture, journal, today, insights, system
sync/         outbox, transport adapter, state machine, reconciliation
storage/      local database, migrations, backup/import/export
ui/           tokens, primitives, chart frame, monument presentation
testing/      fixtures, model vectors, sync scenarios, workflow drivers
```

Components consume stable view models and emit domain commands. They do not write
storage, call network endpoints, recalculate history, or decide merge semantics.
