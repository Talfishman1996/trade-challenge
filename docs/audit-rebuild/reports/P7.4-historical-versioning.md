## Immutable Execution Snapshot

Every accepted trade stores:

```text
modelVersion, modelInputEquity, plannedRiskFraction, plannedRiskDollars,
plannedGrossRR, strategyEquitySource, decisionTimestamp, modelParametersHash,
costProfileVersion, plannedOutcome, grossPnl, netPnl, actual costs
```

The ledger derives realized equity from historical `netPnl`; it never recalculates
stored planned risk when the current formula changes. Current-model comparison is a
separate derived object labeled hypothetical.

## Migration Policy

- Legacy records retain their stored risk fields as `legacy-observed` if present.
- Missing historical fields remain unknown; do not fabricate PCHIP values.
- A one-time optional comparison can calculate `100k-pchip-v1 hypothetical` from the
  recorded pre-trade equity, but cannot overwrite R, phase, or export truth.
- Import preserves source model/version and records migration provenance.
- Model activation is a versioned account event with effective revision/time.
