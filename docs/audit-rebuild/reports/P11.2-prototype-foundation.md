# P11.2 Prototype Foundation

Evidence ID: `EV-P11-FOUND-002`

Summit Ledger implements the P10 foundation rather than reskinning the current app:

- Barlow, Barlow Semi Condensed, and JetBrains Mono are self-hosted as seven WOFF2
  files; no external font request exists.
- mineral black, teal, verified green, amber planning, loss red, and explicit focus
  tokens have single semantic roles.
- Today, Journal, Insights, System, Capture, receipts, and Review use one route-backed
  shell with safe-area offsets and a bounded mobile canvas.
- all active controls meet the 44px minimum geometry contract in measured routes;
  icon controls have names and dialogs have modal semantics, focus entry, focus trap,
  Escape behavior, and focus restoration.
- large-text and reduced-motion settings change document-level behavior without
  creating horizontal overflow in the measured 520px review composition.

The shell preserves the mountain monument as compressed identity while moving
current equity, next risk, capture, latest record, and durability into operational
scan order.
