## Responsibility and Import Map

```text
index.html
  -> src/main.jsx
     -> src/components/App.jsx
        -> useTrades (store/trades.js)
           -> tradeData.js -> risk.js -> constants.js
           -> sync.js -> production Cloudflare Worker
        -> useSettings (store/settings.js) -> risk.js
        -> Home / TradeEntry / Trades / Analysis / Settings

Home
  -> risk model + constants + formatting
  -> EquityCurve / GPSJourney / Celebration

TradeEntry
  -> tag constants + trade date utilities + IndexedDB image adapter

Trades
  -> FilterBar / formatting / phase labels

Analysis
  -> analytics + Monte Carlo + charts / metric primitives

Settings
  -> model constants + sync configuration/status/activity + data import/export

worker/src/index.js
  -> Cloudflare KV binding only; no shared schema package with the frontend
```

There is no router. `App.jsx` owns view selection in component state and lazy-loads
four non-home surfaces. State is split across component state, two localStorage
stores, one IndexedDB database, and one unauthenticated shared cloud blob.

## Dependency and Delivery Baseline

- UI/runtime: React 19.2.4, React DOM 19.2.4, Framer Motion 12.34.3,
  Lucide React 0.575.0, and Recharts 3.7.0.
- Build/style/deploy: Vite 7.3.1, Tailwind CSS 4.2.0, React Vite plugin 5.1.4,
  and Wrangler 4.83.0.
- The package lock is npm lockfile version 3.
- The build has no automated validation command beyond `vite build`.
- `master` triggers a GitHub Pages workflow, while package scripts separately
  deploy the same `dist` directory to Cloudflare Pages.
- `dist/index.html` is tracked, but its referenced hashed JS/CSS assets are ignored.
- The frontend hardcodes the production Worker origin in `src/sync.js`.
- Google Fonts are loaded from the network in `index.html`; there is no local font
  fallback asset package or offline application manifest.
