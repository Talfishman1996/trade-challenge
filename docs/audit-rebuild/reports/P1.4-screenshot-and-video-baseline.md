## Critical Runtime Evidence

Daily-loss gate activation produced a blank application and this runtime error:

`ReferenceError: fmt is not defined at App`

The failure image and browser stack are preserved. `App.jsx` formats the daily loss
inside the conditional gate but does not import `fmt`.

Forced cloud 503 responses produced a second critical truth failure: the compact
control continued to say `Synced 2m ago`, including after a manual sync click. The
sync function returns the string `error`; `runSync` routes that result through its
default ready branch instead of its exception branch.
