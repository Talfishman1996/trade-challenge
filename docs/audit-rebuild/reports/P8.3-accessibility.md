# P8.3 Accessibility

Captured: 2026-07-12 PDT

State: `EVIDENCE_READY`

Evidence ID: `EV-P8-A11Y-003`.

## Scanner and Manual Source Results

- 43/79 visible controls missed the project's 44 px mobile target; many also fall
  near/below WCAG's 24 px minimum without measured spacing exceptions.
- 19/79 controls lacked detected names.
- Settings uses adjacent `<label>` elements without `for`/`id` or wrapping the
  associated range/text input; the scanner correctly sees unnamed controls.
- The global center capture FAB, several icon actions, image remove, modal close,
  filter expand/clear, and chart close lack explicit names.
- Trade Entry has no dialog role/name, focus trap, initial focus contract, Escape/
  Back contract, or inert background.
- Charts have no accessible summaries/tables and rely on visual axes/tooltips.
- Contrast failures: Home 8/22, Projections 13/21, Settings 21/33; worst 2.27:1.
- Risk/profit/progress meaning often depends on color.
- Reduced motion covers only selected Home CSS; Framer transitions, sheet spring,
  confetti, particles, and other loops remain.
- 200% text emulation did not reproduce physical iOS scaling and cannot close reflow.

This converts `F-A11Y-HIGH-001` from experiment-required to open source-confirmed
remediation and strengthens `F-A11Y-HIGH-002`. Formal VoiceOver/TalkBack/switch lab
testing remains excluded by SD-007; ordinary semantic, focus, contrast, reflow, and
keyboard evidence remains mandatory.
